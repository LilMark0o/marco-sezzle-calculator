# AI tooling and prompts

This project was developed with AI assistance as an engineering aid. The final implementation, trade-offs, and verification remain the author's responsibility.

## Skills and workflows used

- **Brainstorming:** scoped the assignment and clarified acceptance criteria.
- **Test-driven development:** defined backend validation through regression tests before implementation.
- **Verification before completion:** required fresh command evidence and explicit reporting of unavailable tooling.
- **Frontend and TypeScript review:** checked the React UI, hook, API client, and Vitest setup against the assignment.
- **Systematic repository review:** compared files, history, remote, tests, and docs with the Sezzle requirements.

## Representative prompts

> Review this full-stack calculator repository against the Sezzle take-home requirements. Produce an explicit gap analysis covering functionality, validation, tests, coverage, documentation, Docker, repository delivery, and AI prompt disclosure. Inspect actual files and commands.

> Design a minimal validation hardening for the generic Go REST handlers that rejects malformed JSON, missing required fields, unknown fields, trailing JSON values, and non-finite numeric values while preserving the existing API and status conventions.

> Work test-first: add focused regression tests, verify they fail for the expected reason, implement the smallest production change, then run all available verification. Do not claim Go tests pass if Go is unavailable.

> Draft concise repository documentation linking to an AI tooling/prompts record and a test-evidence record. Distinguish observed results from environment limitations; do not fabricate coverage.

AI assistance supported review, design exploration, test design, and editing. The repository source, tests, and final decisions remain subject to author review.
